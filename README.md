# HuffmanBMP

Сжатие 24-битных BMP-изображений с помощью алгоритма Хаффмана на Ruby. Учебный проект.

## Возможности

- Сжатие без потерь (lossless)
- Два режима:
  - **3 дерева** — отдельный код Хаффмана для каждого цветового канала (R, G, B)
  - **1 дерево** — общий код для всех байтов изображения
- Переносимый формат сжатых файлов (JSON)
- Консольная утилита
- Чистый Ruby, без внешних зависимостей

---

## Установка

```sh
git clone https://github.com/yourname/huffman_bmp.git
cd huffman_bmp
bundle install
```

## Использование CLI

Синтаксис:

```sh
ruby huffman_bmp [опции]
```
